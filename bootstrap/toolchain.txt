# Informational, not enforced: this is the compiler that built the
# distribution's crt objects, and `ld` merges its version string into every
# binary's `.comment` section — the build-id is a hash over the output, so it
# inherits that string. Two hosts on different Ubuntu point releases therefore
# produce binaries that differ in exactly those two places and nowhere else,
# which is why the self-hosting gate strips `.comment` and `.note.gnu.build-id`
