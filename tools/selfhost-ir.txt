# The lowering parity corpus: files whose LLVM IR `gen2 build` must reproduce
# from Python's `logos build`, byte for byte. One repository-relative path per
# line; blank lines and `#` comments are ignored.
#
# One file, one `.ll`: Python leaves its IR at build/<stem>.ll, so two fixtures
# may not share a stem. Adding a file here is adding a byte-equality claim; a
# file that only partly agrees makes the gate red.
#
# Every fixture under src/logosc/fixtures/ir-lower is listed — the set is not
# "roughly the corpus", it is exactly the directory, and tools/selfhost.sh
# refuses a list whose fixture entries and that directory name different sets.
# The list may also name files outside that directory, and does: the four
# example programs below lower byte-identically and are the first *real*
# programs, not fixtures, to claim parity. A path outside the directory is a
# claim of its own — the gate builds it like any other entry and the floor
# counts it — so it cannot hide a fixture that was added, deleted or swapped.
# The list grew from seven to forty-four fixtures: the two known-different
# files (`string`, `match`) now agree, the shifts and the two wildcard-arm
# shapes have fixtures of their own, the print, string, vector, array, memory,
# pointer and call forms each have one, the layout and borrowed-vector shapes
# the corpus could not see have theirs (`struct-eq`, `struct-pad`, `structs-eq`,
# `structs-pad`, `enumfwd`, `vecref`, `vecref2`), and B3 added the forms the
# corpus needs to be a language rather than a subset: `str-byte`,
# `str-from-i64`, `read-file`, `read-all`, `args`, `run` with its three
# accessors, the result and optional forms (`resok`, `optval`, `tryprop`), the
# concurrency handles (`concurrency`: `chan`/`send`/`recv`, `mutex`/`lock`/
# `unlock`, `atomic` and its three operations), and `sharedptr`, the four
# pointer forms through a `(shared (ptr T))` — `deref`, `set-deref`, `ptr-add`
# and a second `deref` of the result.
#
# B4 added the thunk form: `spawn` (`spawn.logos`, and `examples/matrix.logos`
# below). A thunk is a per-site nested function, and the arena stores a
# function's parameters and blocks as contiguous global ranges (`fparam`/`fpc`,
# `fbase`/`fcnt`), so a thunk cannot be emitted where the site sits. The site
# records the thunk on a per-function queue instead; the queue drains after the
# enclosing `ir-fn-end`, which closes the parent's ranges first, and then the
# parent's f-row is rotated right by the number of thunks so the table reads
# `[t1 … tk, F]` while the thunk blocks stay after the parent's. That rotation
# is what makes the define order Python's — each thunk's define immediately
# before the define that spawns it — byte for byte; a plain drain reproduces
# the same eighteen lines after the parent instead of before it.
#
# C1 adds `vecgetref`: a `(ref (vec T))` operand used by `vec-get` in a
# comparison and by `get` on the element, the two shapes whose type the query
# used to read as the referent rather than its element.
#
# W8 step 3a adds closures: a `(fn :R ((p :T)...) body...)` expression builds a
# per-site nested function `$lambda$N` from the same unit-wide counter that
# names `$spawn$N`, and a value of two words, `{ i8*, i8* }` — the environment
# and the code. Captures travel in the same literal record the spawn thunks
# unpack, one field per captured binding in first-use order, and a call through
# a value is `extractvalue` twice, a `bitcast` to the real signature and an
# `icall` that passes the environment first. The five fixtures are the shapes
# the corpus needs: no capture, one capture, two captures, a closure passed to
# a `(fn ...)` parameter and called there, and a `spawn` beside two closures in
# one function — the last is the counter claim, that `$lambda` and `$spawn`
# interleave and their defines still land in site order before the parent.
#
# Two closure shapes are still not lowered, and no fixture claims them: a named
# function used as a value (`$fnvalue`, a wrapper per function) and a generic
# function's instantiation. `tests/exec/closures.logos` is therefore absent:
# its generic definitions are never spelled by this backend — Python emits ten
# instance functions for them instead (`id$i64`, `apply$i64$i64`, ...) — so the
# file cannot be lowered until instances are. The rest of the positive corpus
# under tests/exec, tests/thread and tests/regress also needs
# `build --test NAME` (skip the module `main`, lower the test body as the entry
# point); that mode does not exist in the port either. A shape the lowerer must
# refuse rather than spell lives beside this directory in
# src/logosc/fixtures/ir-refuse.
#
# The floors in tools/selfhost.sh count the entries below: a pruned list fails
# the gate rather than passing over fewer files, and a separate floor counts the
# fixture entries alone, so a fixture cannot leave while a path outside the
# directory takes its place.
#
# W8 step 2 adds `dirs`: the four directory forms `(read-dir p)`, `(is-dir p)`,
# `(mkdirs p)` and `(path-error p)`. `read-dir` builds its tracked vector the
# way `args` does, so the fixture pins both the copy and the `icmp -- count ==
# 0` branch; `is-dir` is the runtime's integer compared against zero.
#

# than fixtures whose IR is claimed byte-identical. The fourth, `matrix`, is
# B4's end-to-end spawn claim; the first three are hello, json and wc.
