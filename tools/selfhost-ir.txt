# The lowering parity corpus: files whose LLVM IR `gen2 build` must reproduce
# from Python's `logos build`, byte for byte. One repository-relative path per
# line; blank lines and `#` comments are ignored.
#
# One file, one `.ll`: Python leaves its IR at build/<stem>.ll, so two fixtures
# may not share a stem. Adding a file here is adding a byte-equality claim; a
# file that only partly agrees makes the gate red.
#
# Every fixture under src/logosc/fixtures/ir-lower is listed. The list grew from
# seven to twenty-four in W7 B2: the two known-different files (`string`,
# `match`) now agree, the shifts and the two wildcard-arm shapes have fixtures
# of their own, and the print, string, vector, array, memory, pointer and call
# forms the corpus needs next each have one. `fieldset` and `heap` cover
# `set-field`, `deref`, `set-deref` and `ptr-add`.
#
# Still not lowered, and so deliberately absent from this list (no fixture
# claims them): `spawn`/`join`, channels, mutexes and atomics, closures,
# results and optionals (`some`/`none`/`ok`/`err`/`try`), `run`,
# `read-all`/`read-file`, `args`, `str-byte`/`str-from-i64`, and moving or
# freeing a vector through a `(ref …)` binding. They are PR C's list.
#
# The floor in tools/selfhost.sh is the number of lines below: a pruned list
# fails the gate rather than passing over fewer files.
