# The lowering parity corpus: files whose LLVM IR `gen2 build` must reproduce
# from Python's `logos build`, byte for byte. One repository-relative path per
# line; blank lines and `#` comments are ignored.
#
# One file, one `.ll`: Python leaves its IR at build/<stem>.ll, so two fixtures
# may not share a stem. Adding a file here is adding a byte-equality claim; a
# file that only partly agrees makes the gate red.
#
# Every fixture under src/logosc/fixtures/ir-lower is listed — the set is not
# "roughly the corpus", it is exactly the directory, and tools/selfhost.sh
# refuses a list whose fixture entries and that directory name different sets.
# The list may also name files outside that directory, and does: the three
# example programs below lower byte-identically and are the first *real*
# programs, not fixtures, to claim parity. A path outside the directory is a
# claim of its own — the gate builds it like any other entry and the floor
# counts it — so it cannot hide a fixture that was added, deleted or swapped.
# The list grew from seven to forty-three fixtures: the two known-different
# files (`string`, `match`) now agree, the shifts and the two wildcard-arm
# shapes have fixtures of their own, the print, string, vector, array, memory,
# pointer and call forms each have one, the layout and borrowed-vector shapes
# the corpus could not see have theirs (`struct-eq`, `struct-pad`, `structs-eq`,
# `structs-pad`, `enumfwd`, `vecref`, `vecref2`), and B3 added the forms the
# corpus needs to be a language rather than a subset: `str-byte`,
# `str-from-i64`, `read-file`, `read-all`, `args`, `run` with its three
# accessors, the result and optional forms (`resok`, `optval`, `tryprop`), the
# concurrency handles (`concurrency`: `chan`/`send`/`recv`, `mutex`/`lock`/
# `unlock`, `atomic` and its three operations), and `sharedptr`, the four
# pointer forms through a `(shared (ptr T))` — `deref`, `set-deref`, `ptr-add`
# and a second `deref` of the result.
#
# Still not lowered, and so deliberately absent from this list (no fixture
# claims them): `spawn`/`join` — a thunk is a per-site nested function while
# this arena stores a function's parameters and blocks as contiguous global
# ranges (`fparam`/`fpc`, `fbase`/`fcnt`), so emitting one mid-body corrupts the
# enclosing function's ranges; `spawn` therefore refuses with E0002 rather than
# miscompiling — and closures. The positive corpus under tests/exec,
# tests/thread and tests/regress needs `build --test NAME` (skip the module
# `main`, lower the test body as the entry point); that mode does not exist in
# the port, which is why those files are absent too. A shape the lowerer must
# refuse rather than spell lives beside this directory in
# src/logosc/fixtures/ir-refuse.
#
# The floors in tools/selfhost.sh count the entries below: a pruned list fails
# the gate rather than passing over fewer files, and a separate floor counts the
# fixture entries alone, so a fixture cannot leave while a path outside the
# directory takes its place.
#
# Beyond the fixtures: three example programs, the first real programs rather
# than fixtures whose IR is claimed byte-identical.
