## The five decisions this pyramid makes

1. **The challenge is called the Logos Agent Challenge, and Round 1 runs 2026-12-01 → 2027-01-15.** Three tracks: build a program, land a pull request, port or teach.
2. **No money and no swag** — unless the maintainer takes the one pre-launch amendment, which is a single cash award per track declared before `L-7`. The repository has no funding mechanism, so the default is a reputation and merged-code challenge, and the rules say so rather than leaving it to be discovered.
3. **Entries are issues, not discussion threads.** Discussions is off on the repository, and a labelled issue is assignable, searchable and countable. The topic `logos-agent-challenge` is optional and never counted.
4. **Agents are welcome and disclose themselves.** Disclosure is required for credit, never a scoring penalty, and the operator is always the accountable party.
5. **A challenge is also a test harness.** Every entry an outside agent writes is a probe of the language, so each entry's rough edges become `challenge-findings` issues — metric M7, floor 8.

## What is not here

The launch itself. Posting, channel order and the outreach schedule belong to the
launch task; this pyramid supplies the block to post (program §10) and the order
comes from the channel map. The messaging voice rules are the positioning kit's,
not this pyramid's.
